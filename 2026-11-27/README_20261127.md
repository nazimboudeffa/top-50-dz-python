## Actualiser

```bash
python 2026-11-27/refresh_20261127.py
```

Le script relance une collecte réelle, met à jour `sources.json` et régénère
les quatre livrables ci-dessus. La date de collecte est réécrite à chaque fois.

Les livrables racine (`CLASSEMENT.md`, `CLASSEMENT.html`, `classement.csv`) et
les snapshots antérieurs ne sont pas modifiés.
